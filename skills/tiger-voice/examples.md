# Examples

Curated examples are kept with the layer the source messages came from, because they quote real
conversations. Read every `voice/examples.md` that the loaded project rules point to (each layer's
overlay for `tiger-voice` names its files). They are the source of truth: if a rule in `SKILL.md`
and an example disagree, the example wins.

With no layer installed, draft from the rules in `SKILL.md` alone.
